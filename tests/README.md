# Tests

Esta carpeta reúne las pruebas automatizadas del complemento **Ver Coordenadas**.

La batería formal de pruebas para la publicación 1.0.0 se completará durante la etapa de revisión técnica y calidad. Las pruebas deberán cubrir, como mínimo, formatos de coordenadas, polígonos y huecos, multipartes, medidas proyectadas y geográficas, y avisos adaptativos.
